# Provider research and activation

Documentation reviewed 3–4 November 2026. Plans, access and model names can change; owner dashboard entitlements take precedence. No account credit balance or paid API call was verified.

| Capability         | Implementation and official source                                                                                                                                                                                 | Activation status                                                                                                                                      |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ |

App deliberately accepts only PCM WAV, mono 16 kHz, <=20 seconds, even though provider supports additional formats |
| Timbre TTS         | [`POST /api/v1/tts/inference`](https://docs.gnani.ai/api/TTS/tts-inference), Timbre 2.5, Kaveri default, binary WAV response                                                                                       | Adapter and mocked contract tested; live voice/account entitlement unverified                                                                          |
| Evon               | [Official waitlist](https://www.gnani.ai/evon-waitlist) indicates limited access; [internship announcement](https://www.gnani.ai/resources/blogs/great-indian-ai-internship-challenge-2026) is not an API contract | Fail-loud stub. Need official endpoint/auth/model contract, access and written credit coverage; no invented endpoint or automatic fallback             |

| Database/auth      | [Supabase plans](https://supabase.com/pricing)                                                                                                                                                                     | Local migrations/RLS tested. Hosted project, auth, backup and residency configuration needed                                                           |
| Hosting            | [Vercel Hobby](https://vercel.com/docs/plans/hobby), [cron limits](https://vercel.com/docs/cron-jobs/usage-and-pricing)                                                                                            | Hobby personal/non-commercial restrictions and daily scheduling affect launch decisions                                                                |

Credit units are not interchangeable. Gnani programme credits for voice must not be assumed to cover Evon, search or third-party reasoning. Set provider-side spend caps before `PROVIDER_BUDGET_CONFIRMED=true`. Source and transcript content may be sent to configured processors; review retention, training, region and contractual terms separately.

## Legal review sources

The in-app policies are drafts, not legal advice or a completed compliance programme. Review the [FTC CAN-SPAM guide](https://www.ftc.gov/business-guidance/resources/can-spam-act-compliance-guide-business), [ICO business marketing guidance](https://ico.org.uk/for-organisations/direct-marketing-and-privacy-and-electronic-communications/business-to-business-marketing/), [CRTC CASL guidance](https://crtc.gc.ca/eng/com500/faq500.htm), and [MeitY DPDP Rules materials](https://www.meity.gov.in/documents/act-and-policies/digital-personal-data-protection-rules-2025-gDOxUjMtQWa?pageTitle=Digital-Personal-Data-Protection-Rules-2025). Applicable obligations depend on operator, people, jurisdiction, purpose and commencement dates. Publicly listed contacts do not establish blanket permission for outreach. Spectra never auto-sends messages.
